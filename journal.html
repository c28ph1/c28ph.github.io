PROJECT FIVE
Thurs, Jan. 15th A

Today I made a project called Color. The way that it works is that every time you press a key it generates a random color for the background of the website. Each key press generates a random R value, G value, and B value. Every color is made up of some combination of RGB values - so this function can effectively make any color possible.

This is my final project! Number thirteen. Unlucky. This took a long time to code, and there are a lot of complicated functions - but I am very happy with how it turned out.
