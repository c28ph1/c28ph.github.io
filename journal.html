JOURNAL ENTRY ONE
Mon, Nov. 3rd

Today I completed "Motion," my first computer science project. It was not particularly complicated
to create, but there were some harder parts that required more help. The program allows you to
move a rocket ship by pressing on the arrow keys. We had learned how to make these actions occur
with any random key press - but never with specific keys triggering specific actions.


JOURNAL ENTRY TWO
Thurs, Nov. 6th

Today I made a christmas card that I can send to friends and family. The project uses a function to
play a song that I recorded in Voice Memos on my computer. Because the function triggers
multiple tracks to start playing, I was able to add harmonies. For the design of the page, I added
white and green stripes for the theme, and made a simple snowman out of circles whose head you
have to press to play the song.


JOURNAL ENTRY THREE
Mon, Dec. 8th

Today I made a christmas list with randomly circulating presents that I want. I thought that the
function for this project was very interesting - because I created a list of all of the items that
I want, and one is pulled randomly. To make it look a little better, I added some ordinary text
boxes, and I also made the items switch very quickly. I thought that this was funny because
you can barely read any of the items.


JOURNAL ENTRY FOUR
Thurs, Dec. 11th

Today I made a project called Color. The way that it works is that every time you press a key it
generates a random color for the background of the website. Each key press generates a random R
value, G value, and B value. Every color is made up of some combination of RGB values - so this
function can effectively make any color possible.


JOURNAL ENTRY FIVE
Thurs, Jan. 15th

Today I made a project called Confetti. It causes confetti to fall ramdomly from the top of the
screen. Using similar functions to those in my Color project, each confetti that falls has a random
size (length and width), color, rotation, and starting location. I made the background black so
that the colors of the confetti pop out from the screen.
